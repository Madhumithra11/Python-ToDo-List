# 📝 Console-Based To-Do List Application

A simple and user-friendly **Console-Based To-Do List Application** built using **Python**. This application helps users organize their daily tasks by allowing them to add, view, complete, and remove tasks through a command-line interface.

---

## 📌 Project Overview

The To-Do List Application is designed to help users manage their tasks efficiently. It provides a simple menu-driven interface where users can perform common task management operations without requiring any external libraries or databases.

This project demonstrates the use of:
- Python functions
- Lists and dictionaries
- Loops and conditional statements
- Exception handling
- User input and output

---

## ✨ Features

- ✅ Add new tasks
- 📋 View all tasks
- ✔ Mark tasks as completed
- 🗑 Remove tasks
- 🔄 Interactive menu-driven interface
- ⚠ Handles invalid user input gracefully

---

## 🛠 Technologies Used

- **Programming Language:** Python 3
- **Editor:** Visual Studio Code (VS Code)
- **Interface:** Command Line Interface (CLI)
